#  traced-app

python langchain openai langsmith generative-ai llm llm-tracing ai-monitoring
Key Features
- OpenAI integration using LangChain ChatOpenAI.
- Executes multiple prompts in a single run.
- Automatic LangSmith tracing using environment variables.
- Custom LangSmith project configuration.
- Tracks LLM inputs, outputs, latency and token usage.
- Monitors execution cost.
